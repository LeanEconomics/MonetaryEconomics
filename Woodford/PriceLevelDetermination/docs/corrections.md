# Corrections to the source

Places where a claim in Chapter 2 or Appendix A of Woodford (2003) is false, imprecise, or relies
on an unstated hypothesis, and where the Lean statement departs from the printed one. In each
case the Lean statement proves the stated version and cites the original. Entries are recorded
when found and revised if formalisation shows the finding itself to be wrong: in particular, the
tax formula (1.29), p. 76, was at first suspected to hold only when `Δ_t = 0`; it is exact as
printed (`Wicksell.taxes_1_29`). Lean names are relative to the namespace
`Woodford.PriceLevelDetermination`.

With `det f₃ ≠ 0` the printed count plus genericity is exact (`LinearSystems.linDeterminate_iff_of_det`). |

| p. 137 | In the Schmitt-Grohé–Uribe example the target is the unique rational-expectations equilibrium, "even allowing for stochastic equilibria of arbitrary form". | True on every finite event tree, and more generally on every informationally closed system in which information is eventually resolved (`SGUStochastic.sgu_finiteTree_unique`, `SGUStochastic.stoch_unique_of_resolved`); no self-fulfilling inflation holds on every expectation system (`SGUStochastic.stoch_no_hyperinflation`).
