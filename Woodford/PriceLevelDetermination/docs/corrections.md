# Corrections to the source

Places where a claim in Chapter 2 or Appendix A of Woodford (2003) is false, imprecise, or relies
on an unstated hypothesis, and where the Lean statement departs from the printed one. In each
case the Lean statement proves the stated version and cites the original. Entries are recorded
when found and revised if formalisation shows the finding itself to be wrong: in particular, the
tax formula (1.29), p. 76, was at first suspected to hold only when `Δ_t = 0`; it is exact as
printed (`Wicksell.taxes_1_29`). Lean names are relative to the namespace
`Woodford.PriceLevelDetermination`.

## Claims that are false as printed

| Where | Book says | Finding |
| --- | --- | --- |
| fn. 17, p. 84 | Only the difference `log P*_t − (φ_p⁻¹ + 1)ν_t` matters. | The combination that enters (1.39) is `log P*_t − φ_p⁻¹ν_t` (`Wicksell.fn17_corrected`). Counterexample to the printed one: at `φ_p = 1`, `(P*, ν) = (0, 0)` and `(2, 1)` have the same printed combination but give `log P ≡ 0` and `log P ≡ 1` (`Wicksell.fn17_printed_false`). |
| Prop 2.9, pp. 97–98; A.9, pp. 642–643 | For any target `var(π) > 0` and `ρ` large enough there is a rule with `φ_π > 0` achieving it, and `var(î)` is decreasing in `ρ`. | False when `var(π) > var(r̂)`: then for every large `ρ` no rule with `φ_π > 0`, `φ_π + ρ > 1` achieves the target (`InertialRules.prop_2_9_false`, `InertialRules.prop_2_9_printed_false`). With `ρ_r = 4/5` and `var(π) = 2 var(r̂)`, the only determinate rule at `ρ = 2` has `φ_π = 3√10/10 − 6/5 ≈ −0.25` and `var(î) ≈ 0.070 var(r̂)`; at `ρ = 5` the rules have `φ_π = −6/5` or `−36/5`, with `var(î) = 0.16 var(r̂)` or `5.76 var(r̂)`, so `var(î)` is not decreasing (`InertialRules.e2_rho_two`, `InertialRules.e2_rho_five`, `InertialRules.e2_counterexample`). Correct: if `\|ρ_r\| < 1` and `0 < var(π) ≤ var(r̂)`, then for every `ρ ≥ 1` there is a unique admissible `φ_π`, and larger `ρ` gives strictly smaller `var(î)` (`InertialRules.prop_2_9_corrected`, `InertialRules.prop_2_9_exists`, `InertialRules.prop_2_9_unique`, `InertialRules.prop_2_9_monotone`). |
| (A.25), p. 643 | `σ(î) = σ(r̂) − h(ρ)σ(π)`. | `var(î) = (σ(r̂) − h(ρ)σ(π))²`, so `σ(î) = \|σ(r̂) − h(ρ)σ(π)\|`; without the absolute value it can be negative (`InertialRules.msq_irfI_eq_sq`, `InertialRules.sigma_i_formula`). |
| A.4, p. 637 | For `\|a\| = 1`, another bounded solution is `z_t = z̄_t + (z_{t−1} − z̄_{t−1}) + ν_t`, and `∑E_t u_{t+j}` is a bounded solution for any stationary ARMA `u`. | The recursion is valid only for `a = 1`; it fails at `a = −1` (`ForwardSolution.printed_A17_one_solves`, `ForwardSolution.printed_A17_fails_neg_one`). Correct: `d_t = a⁻¹d_{t−1} + ν_t` (`ForwardSolution.unit_sunspot_solves`, `ForwardSolution.unit_sunspot_bounded`), and the forward sum is `∑aʲE_t u_{t+j}`, which needs forecast decay, e.g. a mean-zero AR(1) (`ForwardSolution.forwardSeries_solves_of_decay`, `ForwardSolution.ar1_decay`). A bounded solution need not exist: with `u_t = c(−1)ᵗ`, `c ≠ 0`, at `a = −1` there is none (`ForwardSolution.no_bounded_solution_unit`). When one exists there are uncountably many (`ForwardSolution.bounded_solutions_not_countable`). |
| A.6, p. 639 | `π_t − E_{t−1}π_t = −log(1 − ν_t)`. | `π_t − E_{t−1}π_t = −log(1 − ν_t) + E_{t−1}log(1 − ν_t)` (`ExogenousRate.surprise_A6`). Counterexample: `ν = ±½` with equal probability gives `E log(1 − ν) = ½ log(3/4) < 0` (`ExogenousRate.coin_info_zero`, `ExogenousRate.printed_surprise_false`). Distinctness of the equilibria still holds (`ExogenousRate.sunspotPrice_injective`). |
| A.3, p. 633 | The linear approximation is accurate up to an error of order `O(‖u‖²)`. | Needs `C²` (or a Lipschitz derivative); under `C¹` alone only `o(‖u‖)` holds (`LocalIFT.hasFDerivAt_implicitSol`). Counterexample: `g(x, ν) = 2x + ν + ν^{3/2}` is `C¹` and determinate, and along `ν_t ≡ ξ` the error is exactly `ξ^{3/2}` (`LocalIFT.not_second_order_of_C1`). Proved under `C^{1,1}` and `C²` (`LocalIFT.second_order_accuracy`, `LocalIFT.second_order_accuracy_of_contDiff_two`, `LocalIFT.second_order_loc`). The same applies to the `O(ξ²)` claims of Props 2.3, 2.6–2.8 and 2.11–2.13. |
| §4.1, p. 127 | For any inflation rate above the target there is an equilibrium in which inflation grows without bound. | Needs a global hypothesis: exactly, no steady state of (4.6) above `Π*` (`GlobalDynamics.inflation_unbounded_iff`, `GlobalDynamics.inflation_unbounded46`). Counterexample: `β = 1/2`, `Π* = 1`, `φ(Π) = max(0, min(3Π − 2, 2))` is continuous, nondecreasing and satisfies the Taylor principle at `Π*`, yet `Π_t ≡ 3/2` solves (4.6) (`GlobalDynamics.phiCE`, `GlobalDynamics.e6_counterexample`). |
| §4.1, p. 130 | In the separable case `F(m)` is positive, increasing and convex. | Not convex: with `c = 1` and `v′(m) = e^{−m}`, `F(3) > (F(2) + F(4))/2` (`MoneyTargetingDynamics.vpE7`, `MoneyTargetingDynamics.e7_counterexample`). Convexity is not needed: single crossing holds without it (`MoneyTargetingDynamics.sep_single_crossing`). |
| §4.2, p. 133 | Eventually `1 + φ(Π_T) ≥ μ̄` for all `T`. | The inequality is reversed: eventually `1 + φ(Π_T) ≤ μ̄` (`MoneyTargetingDynamics.e4_corrected_inequality`). The printed version is false whenever the path converges to `Π**` with `1 + φ(Π**) < μ̄` (`MoneyTargetingDynamics.e4_printed_inequality_false`). |
| A.15, p. 648 | `Λ + Γ(1 − γ) − 1 = (1 + η_iχ)φ_π/γ₀` and `Λ → 1 + η̃χ̄Φ_πψ/(1 + η̃χ̄Φ_πψ)`. | `Λ − Γ̃(1 − γ) = ρ/γ₀`; in fact `Λ = 1/γ₁`, so `Λ → 1/(1 + η̃_iχ̄Φ_πψ)` (`ShortPeriod.LambdaC_sub`, `ShortPeriod.LambdaC_eq`, `ShortPeriod.prop_2_15_limits`). The printed identity fails at `η_iχ = 1`, `φ_π = 1`, `ρ = ½` (−1/10 against 4/5) (`ShortPeriod.book_identity_false`); the printed limit is wrong for every `χ̄ ≠ 0`, e.g. 1.0863 against the true 0.9137 (`ShortPeriod.book_Lambda_limit_wrong`, `ShortPeriod.E3_numbers`). The conclusions (finite, positive, continuous limits) are unaffected (`ShortPeriod.limits_continuousOn`, `ShortPeriod.limits_pos`). |
| p. 118 | If `σ > 0.5` then `χ > 0`. | `χ > 0` iff `σ > 1/(2β)`, about 0.50505 at `β = .99` (`Calibration.chi_pos_iff_sigma`, `Calibration.sigma_threshold_bounds`). Counterexample: `σ = 0.502` (`Calibration.book_sigma_claim_false`). |
| A.17, p. 655 | `B(Π)` is monotone and tends to `φ_πθ`; no `Π_{t+1}` solves (4.5) once `Π_t ≥ Π̄`; hence no hyperinflation and a unique perfect-foresight equilibrium. | The argument needs `B` decreasing, i.e. `β + θΠ*(1 − φ_π) > 0`; under that hypothesis the full result holds (`SchmittGroheUribe.sgu_no_hyperinflation`, `SchmittGroheUribe.sgu_unique_pf_equilibrium`), and `Π̄` exists automatically (`SchmittGroheUribe.sguPibar_spec`). When it is negative the conclusion itself fails: at `β = 1/2`, `θ = 1`, `φ_π = 3/2`, `Π* = 3`, `Ȳ = 1`, `D_t = 2ᵗ`, the bound is `Π̄ = 5/3 < Π*`, `B` is not decreasing, `Π_t = 4` has the successor 18/7, and both `Π ≡ 3` and the path from `Π₀ = 4` (staying in [32/13, 4]) are equilibria satisfying (4.4) and (1.24) (`SchmittGroheUribe.gE5`, `SchmittGroheUribe.phiE5`, `SchmittGroheUribe.e5_counterexample`). |

## Claims that need a changed statement

| Where | Book says | Finding |
| --- | --- | --- |
| Prop 2.1, pp. 68–69; A.1, p. 628 | (1.7) and (1.9) are equivalent to (1.12). | The sufficiency half needs the spending series to converge at every date and state, not only at date 0; with that hypothesis the equivalence is exact (`IntertemporalBudget.prop_2_1_iff`, `IntertemporalBudget.exists_wealth_of_ibc`). |
| p. 70 | (1.13) holds with equality iff the flow constraint holds with equality and (1.18) holds. | Exact when quantified over every date (`IntertemporalBudget.ibc_eq_iff_flow_eq_and_tvc`). From equality at a single date `t` one gets only that later slacks have zero discounted expectation `E_t[Q_{t,t+n}s_{t+n}] = 0` (`IntertemporalBudget.flow_eq_and_tvc_of_ibc_eq`). |
| Prop 2.2, p. 72; A.2 | Hypotheses include (1.23). | (1.23) is not used: (1.22) ⇔ (1.24) without it (`Transversality.prop_2_2`, `Transversality.prop_2_2'`). |
| p. 79 | Near the steady state, with `D_{t+1}/D_t = γ_D < π̄/β`, condition (1.24) is necessarily satisfied. | True for the Wicksellian rule when marginal utility is bounded and the fluctuations keep `\|D_{t+1}\| ≤ γ\|D_t\|` with `βγ < θ` (`LocalIFT.wicksell_tvc`, `LocalIFT.tvc_of_bounds`). Under a Taylor rule the price level is not anchored, so the inflation band `ε` enters: `βγ < θe^{−ε}`, which holds only for `ε` small enough (`LocalIFT.taylor_tvc`, `LocalIFT.exists_eps_tvc`). The fiscal hypothesis cannot be dropped: with `D_T = β^{−T}` the steady state violates (1.24) under either rule (`LocalIFT.wicksell_tvc_fails`, `LocalIFT.taylor_tvc_fails`). |
| pp. 81, 91 | `φ_p`, `φ_π` are the elasticities of `φ`. | They are the elasticities of `1 + φ`, i.e. `φ′/(1 + ī)`, since `î` is the log deviation of `1 + i` (`LogLinear.hasFDerivAt_wicksell`, `LogLinear.hasFDerivAt_taylor`). |
| Prop 2.3, p. 82; Prop 2.6, p. 91 | Determinacy for `φ_p > 0`, resp. `φ_π > 1`. | Determinacy holds iff `\|1 + φ_p\| > 1`, resp. `\|φ_π\| > 1`, so `φ_p < −2` and `φ_π < −1` also determine the solution (`Wicksell.determinate_iff`, `TaylorPrinciple.prop_2_6_iff`); in the exact model, local determinacy for `\|φ_π\| > 1` and a continuum for `\|φ_π\| < 1` (`LocalIFT.taylor_local_determinacy`, `LocalIFT.taylor_local_indeterminacy`). At `φ_π = 1` a bounded solution may fail to exist, and when one exists it is not unique (`TaylorPrinciple.one_no_bounded`, `TaylorPrinciple.one_not_unique`). |
| p. 97; A.8, p. 641 | Negative `φ_π` can be determinate when `ρ > 1`. | `ρ > 1` is not needed: every nonzero `φ_π > 1 − ρ` is determinate (`InertialRules.determinate8_superinertial_neg`); `ρ > 1` only makes that range contain negative values (`InertialRules.determinate8_exists_neg`). |
| Props 2.7, 2.8, 2.12, 2.13 | Determinate or indeterminate according to the log-linear conditions, including the boundary cases. | In the exact model the linearisation decides only the strict cases: local determinacy when `\|b\| < \|a\|` and a continuum of equilibria when `\|a\| < \|b\|` (`LocalIFT.local_determinacy_loc`, `LocalIFT.local_indeterminacy_loc`). At `Φ_π = 1`, `\|φ_π + ρ\| = 1`, `\|A\| = \|B\|`, `\|γ₀\| = \|γ₁\|` the exact model is not decided. |
| (A.9), p. 632 | Determinacy holds "generically" iff the roots are outside the unit circle. | For the scalar forward class it is an exact iff: `a + bS` is invertible on `ℓ∞` iff `\|b\| < \|a\|` (`LocalIFT.isUnit_TOp_iff`, `LocalIFT.isUnit_linOp_iff`). |
| Prop 2.11, p. 107 | Uniqueness among equilibria with `P_t/M_t ∈ 𝒫` and `i_t ∈ I`. | The restriction `i_t ∈ I` is unnecessary: `i` is pinned down by (3.3) (`Nonlinear.mg_local_determinacy`). |
| Props 2.12–2.13, pp. 115–116 | Determinacy stated under (3.16). | The exact condition without (3.16) is `\|1 + η_iχφ_p\| < \|1 + (1 + η_iχ)φ_p\|`, resp. `\|γ₁\| < \|γ₀\|` for `φ_π ≠ 0`; `φ_π = 0` is never determinate (`NonSeparable.prop_2_12_iff`, `NonSeparable.det213_iff`, `NonSeparable.not_det213_zero`, `Nonlinear.nsw_local_determinacy`). |
| Prop 2.12, p. 116 | The weights `φ̃_j` are positive as long as `χ > −1/(φ_pη_i)`. | `φ̃_0 > 0` also needs `1 + η_iχ > 0`. This follows from (3.16), so it holds inside the proposition, but not from `χ > −1/(φ_pη_i)` alone when `φ_p < 1` (`NonSeparable.phiT212_pos`). |
| Prop 2.14, p. 121 | Hypothesis `φ_π ≠ 1`. | Not needed: at `φ_π = 1` the sign condition fails and the result still holds (indeterminate) (`ShortPeriod.prop_2_14`). |
| p. 127, fn. 61 | It suffices that `λ` not be too strongly increasing in `i`. | Not quantified in the book. Sufficient: `Π/λ(φ(Π))` strictly increasing and `λ(i) ≤ (1 + i)λ(0)` (`GlobalDynamics.self_fulfilling_deflation45_gen`, `GlobalDynamics.deflation45_exists_gen`, `GlobalDynamics.antitone_lam_gives_gen`). Some restriction is needed: with `λ(i) = 1 + i` a path from `(β, Π*)` jumps to `Π*` instead of converging to `β` (`GlobalDynamics.phiCE45`, `GlobalDynamics.deflation45_counterexample`). |
| A.6, p. 639 | `ν` has mean zero. | Not needed for the Euler equation; it is used only for the distinctness of the equilibria (`ExogenousRate.sunspot_fisher`, `ExogenousRate.sunspotPrice_injective`). |
| A.16, (A.47), p. 651 | Separable utility gives `χ < 0`. | Only if `u_mm < 0` strictly; it is an iff (`Timing.chiLS_neg_iff_of_separable`). |
| A.17, p. 654 | The elasticity is bounded below 1. | Below 1 at each `i`, but not uniformly: it tends to 1 (`SchmittGroheUribe.elasticity_lt_one`, `SchmittGroheUribe.elasticity_tendsto_one`). |
| A.9, p. 642 | `π_t = φ_π⁻¹(î_t − î_{t−1})`. | `π_t = φ_π⁻¹(î_t − ρî_{t−1})` (`InertialRules.irfPi_from_irfI`, `InertialRules.var_pi_book_route`). |
| (A.43), p. 650 | `M_{t+1}`. | `M_{t+1}/P_{t+1}` (`Timing.euler_A42_iff_A43`). |
| A.17, p. 655 | `A` and `B` tend to `θ` and `φ_πθ`. | `θ/Ȳ` and `φ_πθ/Ȳ` (`SchmittGroheUribe.sguA_tendsto`, `SchmittGroheUribe.sguB_tendsto`). |
| §4.1, p. 124 | Using the flow government budget constraint (1.7). | The government constraint is (1.25); (1.7) is the household's (`GlobalDynamics.ricardian_step`). |

## Hypotheses the book leaves implicit

| Where | Implicit hypothesis | How it is stated |
| --- | --- | --- |
| Throughout | Conditional expectations satisfy the pull-out property `E_t(ay) = aE_t y` for `a` known at `t` | Not implied by the expectation axioms; a hypothesis where used (`ExpectationSystem.PullOut`), proved for perfect foresight and every finite event tree (`perfectForesight_pullOut`, `ExpectationsFiniteTree.finiteTree_pullOut`) |
| A.6, p. 639 and throughout | A function of variables known at `t` is known at `t` | Not derivable from the expectation axioms; stated as `ExogenousRate.Closed`, proved for perfect foresight and finite trees (`ExogenousRate.perfectForesight_closed`, `ExogenousRate.finiteTree_closed`); elsewhere adaptedness of such functions is a hypothesis |
| (1.10), p. 68; Prop 2.1, A.1 | (1.10) bounds a possibly signed series, and the proof interchanges `E_t` with infinite sums | Absolute summability `IntertemporalBudget.IncomeSummable` and conditional monotone convergence `AssetPricing.MonotoneConvergence`, the latter proved for perfect foresight and finite trees (`AssetPricing.perfectForesight_monotoneConvergence`, `AssetPricing.finiteTree_monotoneConvergence`) |
| A.3; Props 2.3, 2.6–2.8, 2.11–2.13 | Smoothness of the rule and of preferences for the `O(ξ²)` claims | `C²` (or `C^{1,1}`) at the steady state (`LocalIFT.second_order_loc`, `LocalIFT.second_order_accuracy_of_contDiff_two`) |
| Props 2.3, 2.6; A.3 | Gross interest rates and marginal utility stay positive | `1 + φ > 0` for the scalar Wicksell and Taylor models (`LocalIFT.wicksell_local_determinacy`, `LocalIFT.taylor_local_determinacy`); for Props 2.7, 2.8 and 2.11–2.13 the hypotheses are local (`LocalIFT.local_determinacy_loc`) and positivity is derived near the steady state (`Nonlinear.nsw_pos_at`, `Nonlinear.nsi_pos_at`) |
| p. 79 | Bounded marginal utility for (1.24) near the steady state | `u_c ≤ U` (`LocalIFT.tvc_of_bounds`, `LocalIFT.wicksell_tvc`) |
| (4.2), p. 124 | `α > 0` in the Ricardian rule | Needed: with `α = 0` the transversality condition can fail (`GlobalDynamics.ricardian_tvc`, `GlobalDynamics.ricardian_tvc_fails_of_alpha_zero`) |
| pp. 132–133 | The target path itself satisfies the transversality condition | Only if `βμ̄ < Π*` (`MoneyTargetingDynamics.target_tvc_iff`); assumed in `SchmittGroheUribe.sgu_unique_pf_equilibrium` |
| Prop 2.13, pp. 116, 646 | `i^m_t = ī^m_t` (time-indexed) | The proof sets `î^m = 0`; formalised with a constant `ī^m` (`NonSeparable.Eq213`) |

| Prop 2.9, p. 97 | Variances are per unit innovation variance | `∑ψ_j²` of impulse responses (`InertialRules.msq`, `InertialRules.acov1`); the innovation variance cancels in every claim |
